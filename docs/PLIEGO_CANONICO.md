# Pliego canónico · E-Actividad 4.2

## Obligatorio

Según el pliego del profesor facilitado para el proyecto:

- Crear un CRUD con JavaScript y ReactJS. Persistir los registros con la API localStorage y demostrar la actualización del DOM.
- Diseñar para la Cátedra Dr. José Gregorio Hernández. Usar y explicar ejemplos de HTML5.
- Aplicar CSS propio, diseño responsive y buena sintaxis. Trabajar sin plantillas ni copiar los ejemplos de apoyo.
- Entregar video explicativo, Figma y código en GitHub. El grupo admite hasta cuatro integrantes.

## Decisiones de producto

El gestor administra actividades formativas con ocho campos visibles. React mantiene la lista en estado y renderiza el DOM a partir de ella. El diseño editorial usa una paleta propia. La instalación comienza con una lista vacía para que toda actividad visible provenga del usuario.

La contribución de Martin Alejandro Morfe Carballo comprende filtros por tipo y estado, vacío filtrado, accesibilidad de esos controles, navegación y foco asociados, revisión accesible de Editar/Eliminar y pruebas específicas.

## Opcional

Indicadores calculados por estado y despliegue en GitHub Pages como soporte de demostración.
